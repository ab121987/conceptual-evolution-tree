# PARAMETER_RELATIONSHIP_CONTEXT.md

## Purpose

This project explores how webpages can be used as experimental artefacts for thinking through parameter relationships in open systems.

The starting point is a previous closed-system diagram developed from magnetised thermoplastic experiments. That diagram mapped how stimuli, material states, design parameters, and responses interacted over time.

The new webpage should not simply recreate the diagram. It should use the diagram as a stepping stone to explore what happens when parameter relationships become unstable, evolvable, paused, broken, or recoupled in open systems.

---
 
## Reference Image Description

The reference image represents a closed material system.

It maps relationships between:

* stimuli
* material states
* design parameters
* direct and indirect associations
* time windows
* parameter responses
* captured or disconnected properties

The system includes stimuli such as:

* heat on / melting
* liquid state change
* locally induced magnetic stimulus
* global gravity stimulus
* heat off / solidifying
* solid state change

It includes material and design parameters such as:

* volume
* rigidity
* large surface texture
* residual volumes
* smooth surface texture
* opacity
* fine-grain texture
* rippled texture
* graduated patterns

The diagram shows that parameter relationships are not always stable.

Some relationships are:

* directly coupled
* indirectly coupled
* diminished
* paused
* disconnected
* re-emerging
* captured and maintained

The bottom of the diagram shows temporal windows where different responses become possible, disappear, or become fixed.

---

## Conceptual Shift

The reference image describes a relatively closed system where the main stimulus-response relationships are known.

The new webpage should ask:

What happens when those relationships exist in an open system?

In an open system, relationships may:

* form unexpectedly
* weaken
* disappear
* pause
* reappear
* mutate
* recouple with different parameters
* become influenced by external agents
* become influenced by multiple simultaneous stimuli
* generate indirect or delayed responses

The webpage should therefore explore parameter relationships as living, evolving, and unstable rather than fixed.

---

## Core Research Question

How can webpages be used to explore what happens when parameter relationships become unstable, evolvable, paused, broken, or recoupled in open systems?

---

## Design Aim

Create an animated webpage that behaves like an exploratory parameter field.

The webpage should show:

* parameters as nodes
* relationships as lines or paths
* stimuli as events entering the system
* time windows as changing zones or phases
* relationship states as visual changes
* parameter behaviours as animated responses

The page should make it possible to see relationships forming, weakening, breaking, pausing, and recoupling over time.

---

## Relationship States

Each relationship should have a state.

Suggested relationship states:

* active
* direct
* indirect
* diminished
* paused
* broken
* disconnected
* recoupled
* emergent
* captured
* residual
* speculative

These states should be visually distinct.

For example:

* solid line = direct active relationship
* dashed line = indirect relationship
* faded line = diminished relationship
* dotted line = speculative relationship
* broken line = disconnected relationship
* pulsing line = unstable relationship
* reappearing line = recoupled relationship

---

## Important Constraint

Do not treat this as an optimisation system.

The webpage should not try to find the best parameter state.

It should not rank outcomes.

It should not suggest an optimal configuration.

Instead, it should act as a thinking device that helps explore how relationships change over time.

---

## Position Within the Wider Website

This project will sit inside the wider conceptual evolution tree website.

Within that website, the Windows of Influence project should be treated as one project page or branch within the larger body of design explorations.

Its role is to explore how closed-system material relationships can become a stepping stone toward open-system, evolvable parameter relationships.

The conceptual evolution tree should link to this project page, but the tree itself should not reproduce the full animated relationship system.
