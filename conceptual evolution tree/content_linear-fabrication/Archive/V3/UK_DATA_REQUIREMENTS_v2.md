# UK LINEAR FABRICATION — DATA REQUIREMENTS
Updated 2026-07-24

## Distribution decision
Remove **Distribution** from the primary material backbone.

Use:
**Virgin Resources → Extraction → Material Processing → Fabrication / Manufacture → Use / Consumption → End of Use**

Retain **Distribution / Transport** as a secondary service overlay. Future evidence can show freight tonne-km, fuel/electricity and CO2/CO2e between multiple lifecycle transitions.

## Use → End of Use logic
Build this from final-product waste/discard classifications rather than one generic waste total.

Priority classes:
- textiles/apparel
- WEEE/electrical/electronic products
- furniture/furnishings
- leisure/recreation/sport products
- vehicles/transport products
- built structures when demolition-only data are isolated
- packaging as secondary
- other manufactured products

Exclude food/agriculture by default.

## A — quantitative evidence usable now
- selected ONS domestic-extraction material inputs (partial)
- used textiles generated
- furniture/furnishings historical disposal proxy
- WEEE/scrap and textile collection proxies
- packaging recycling as a secondary weak-loop example

These are selected evidence streams, not a complete balanced UK system.

## B — next quantitative work
1. ONS imports/direct material input for object/structure materials.
2. ONS/BGS sand, gravel, clay and other structural mineral categories.
3. DESNZ ECUK stage allocation for energy.
4. DfT freight + fuel/emissions mapping for Distribution/Transport overlay.
5. ONS GHG-by-SIC → stage mapping for CO2 branches.
6. Dedicated Environment Agency WEEE series.
7. Demolition/end-of-life-specific built-structure waste.

## C — annotation/placeholder for now
- habitat loss
- species loss
- labour exploitation
- FORM IMPOSED
- DISCOURSE REMOVED

Land disturbance may later become quantitative in ha/km² where stage-specific evidence exists.

## Principle
Enough robust relationships can paint the picture; the overview does not need to enumerate the whole economy.
Show major supported flows, bundle compatible minor flows as `Other`, and drill down later into prosthetics, buildings or specific materials.
