# Next Data Requirements — Linear Manufacturing Sankey

This note summarises what the current MIT global test data supports, and what still needs UK- or project-specific evidence before it should become a quantitative ribbon in the Linear Manufacturing Sankey.

## Already Supported By The MIT Test Data

- Material throughput from extraction into material processing.
- Material throughput from material processing into fabrication / manufacture.
- Material throughput from fabrication / manufacture into use / consumption.
- Energy inputs into extraction, material processing, fabrication / manufacture, use / consumption and end-of-use activity.
- Landfill and losses as terminal output categories.
- Weak return flows from end of use into material processing and fabrication / manufacture.

## Not Supported In The Current Test Mapping

- Distribution as a robust material throughflow stage.
- Direct Use / Consumption to End of Use flow.
- Stage-specific carbon dioxide / emissions outputs.
- Stage-specific land loss, habitat loss or species loss.
- Social / labour exploitation as a quantified flow.

## A. Likely Quantitative Ribbons Now

- Material throughput.
- Energy inputs.
- Recycling / recovery where records explicitly define return flows.
- Landfill / losses where records explicitly define terminal outputs.

## B. Likely Quantitative Ribbons Later With UK Evidence

- Distribution / freight throughput.
- Use / Consumption to End of Use.
- Carbon dioxide / emissions by stage.
- UK landfill, incineration, recycling and exported waste pathways.
- Industry- or project-specific material processing and manufacturing losses.

## C. Better As Annotations / Placeholders For Now

- Land loss.
- Habitat loss.
- Species loss.
- Social / labour exploitation.
- Broader environmental externalities where no robust stage-specific quantity exists.

## Immediate Data Tasks

- Decide whether Distribution should remain visible as a synthetic unresolved stage in the MIT test view, or be removed from the material backbone until freight data is added.
- Add evidence that links Use / Consumption to End of Use, otherwise keep that gap explicitly labelled as absent in the current test dataset.
- Review unmapped MIT categories before translating this into a UK manufacturing evidence model.
- Keep speculative/conceptual impact categories visibly separate from source-supported quantitative ribbons.
